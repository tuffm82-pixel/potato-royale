## [⬇ DOWNLOAD THE GAME TO KEEP](https://github.com/tuffm82-pixel/potato-royale/raw/refs/heads/main/potato-royale.zip)

The download saves a ZIP containing the complete game, source code and multiplayer server. Extract it, then double-click **PLAY.cmd** on Windows. It needs Node.js 22 or newer (the bundled Codex runtime also works).

Your cards, decks and trophy progress save automatically in the browser you play in. Keep using the same browser and website address to keep that save.

**Practice works immediately.** Real-player matches and friends require a connected multiplayer server; open Friends → Game server to enter its address. GitHub Pages hosts the game interface, not the multiplayer server.

Champions have separate ability buttons with an additional cooking-oil cost. All 127 cards have pencil-style artwork and in-game cutout animations.
