A homemade pencil-comic card battler with 127 cards, 30 arenas, separate paid Champion abilities, and live cutout animations. Browser progress saves automatically.

Practice is playable on GitHub Pages. Real-player matchmaking and friend battles need a separately hosted server. The downloadable ZIP includes that server and the full editable source.
